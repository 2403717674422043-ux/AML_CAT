   Inspects raw CIC-IDS-2017 Friday DDoS network flow capture, checks column integrity,

   .\.venv\Scripts\python.exe src\preprocessing.py

PART 5: PORT CONFLICT & TROUBLESHOOTING RUNBOOK
--------------------------------------------------------------------------------

If port 8000 or 8501 is occupied by a previously running process:

1. Identify the process ID (PID) occupying port 8000 or 8501:
   Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue | Select-Object LocalAddress, LocalPort, OwningProcess
   Get-NetTCPConnection -LocalPort 8501 -ErrorAction SilentlyContinue | Select-Object LocalAddress, LocalPort, OwningProcess

2. Terminate the blocking process using its PID (replace <PID> with the actual process ID):
   Stop-Process -Id <PID> -Force

3. Custom Ports Configuration:
   • To run FastAPI on port 8080:
     .\.venv\Scripts\python.exe -m uvicorn api.main:app --host 0.0.0.0 --port 8080

   • To configure Streamlit to point to custom API port:
     $env:DDOSGUARD_API_URL = "http://localhost:8080"
     .\.venv\Scripts\python.exe -m streamlit run dashboard\app.py --server.port 8502
